# 每日上架（模板，每日傍晚）

按 mercari-listing 技能执行当天上架轮次：

1. 读 `<工作区>/config.md` 确认发布授权范围；授权外品类只建草稿。
2. 取候选：只取现货（ordered／in_hand），以 drafts/listed 交叉核对去重；候选不合格自动顺延下一件（最多 3 件）。
3. 每件走全程：取图落地图片文件夹 → 逐张核款 → 文字包 → CDP 克隆建草稿／发布（publish-flow 定版顺序）→ 编辑页补特徴 → 商品页终检。
4. 登记 listed.json／drafts.json（改前备份），日志写 `<工作区>/hidden_files/run-<日期>-1730.md`。
5. 环境受阻（执行机离线、登录态失效、Mercari 拦截）按 mercari-ops 拦截纪律处理并报告，不硬刷页面。
6. 向用户报告：今天发了几件（m 编号＋价格）、跳过几件及原因、待人工事项。

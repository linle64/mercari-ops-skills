# 定时任务模板

五个模板对应 mercari-setup 阶段 4 的任务表。用你运行时的定时任务机制（如 Muse 的 cron）创建，`<工作区>` 换成实际路径。**先手动跑一轮验证，再启用定时；第一周只产草稿和报告，不自动发布。**

| 文件 | 节奏建议 | 干什么 |
|---|---|---|
| weekly-select.md | 每周日上午 | 全量选品、过三道闸、补候选池 |
| daily-pool-guard.md | 每日傍晚（上架任务之前） | 查候选池水位与现货水位 |
| daily-list.md | 每日傍晚 | 现货范围内建草稿／发布＋登记 |
| comment-patrol.md | 每日午间、晚间各一份 | 两号评论巡逻、起草待确认 |
| daily-ledger-refresh.md | 每日早晨（可选） | 轻量对账、看板数据刷新 |

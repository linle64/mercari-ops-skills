# 发布定版流程（CDP 克隆）

环境准备（克隆启动、通道、文件选择器）见 mercari-ops 的 `references/environment.md`，先读再动手。本文件只讲出品表单本身。驱动分两段：主流程＋finish（补配送／复核／发布）。

## 总顺序（顺序错了会被 AI 覆盖或被下拉重置）

1. 先走会跳页的步骤：类目（wizard 往返）、状態。
2. 再传图、填文字、下拉。
3. **配送の方法最后设**——「配送料の負担」下拉会重置配送方法，全部下拉先设完，配送方法压轴。
4. 发布（或存草稿）后去编辑页补特徴，再到商品页终检。

原因：wizard 往返后手填标题会被 AI 标题替换、说明文被 AI 续写、状態被预置为中古等级——标题／说明必须在 wizard 之后回填；状態在草稿编辑页改。

## 图片

- 传图先弹「出品画像」模态框，逐张加，点「次へ」进表单。
- CDP 用 `DOM.setFileInputFiles` 直塞图，免文件选择器。A 号（Chrome 克隆）先把图拷到 /tmp 再塞（读不到桌面文件内容）；B 号（Brave 克隆）可直接用图片文件夹路径。
- 张数核对看商品页的 `1 / N` 计数，不要数缩略图：同一组图可能在两个容器各渲染一份（12 缩略图＝6 张×2），state 以计数为准。无障碍树的缩略图计数含空添加槽、虚高，同样不可信。

## 类目

- 父级（ファッション→レディース→小物）点外层 a 正常钻取；**叶子必须点行内 `button.rowButton`**——点外层 a 只跳回 create 页、不设类目。
- 点 rowButton 后跳 `/sell/wizard`，点「出品画面に戻る」回表单，类目才落位（图文不丢）。
- 类目页顶部有 AI 建议 chip，一点即选叶类目，可优先用。

## 文案写入

- **AX 赋值（fill）对 Mercari 的 React 表单不生效**，不要用。
- 定版：点击聚焦字段 → 全选（覆盖 AI 生成值）→ **一次输入写入全文**。说明文换行以 `\n` 写进同一段（内嵌换行全部生效）；**文本不得以 `\n` 开头**（开头换行会被吞、首行次行粘连）；不要逐行输入＋回车。
- 价格框：聚焦后输入数字即可。
- 写完必须读回全文＋字数核对，才算写入成功。

## 原生下拉（select）

- CDP 路线优先用原生 value setter＋input/change 事件写 React 表单。
- 桌面自动化路线（备用）：其 `select` 动作对 Chromium 原生 select 恒超时，弃用。定版：`focus` combobox（不开菜单）→ ASCII 开头选项（発送までの日数等）直接按首字符键即写入；日文选项按 ↓ 开菜单 → 截图读菜单（高亮＋✓为当前项）→ 按 ↓/↑ 数到目标 → Return 提交 → 读回核对。选项顺序实测：汚れ＝[選択してください, あり, なし]；都道府县为 JIS 顺序。
- 焦点铁律：物理动作只落最前台窗口，每个物理动作前先 activate 目标应用；点击是否生效只能靠状态变化验证（截图正常≠点中了）。

## 状態

- 新建表单里不要点状態链接离开页面（未保存会丢数据）。
- 草稿保存后在编辑页改：点「変更する」→ `/sell/conditions` 列表页 → 点「新品、未使用」→ 自动回编辑页 → 页底「上書き保存する」→ 重开编辑页复核持久化。

## 特徴（カラー／素材／汚れ）

- ベルト类目作成表单只有「汚れ・破れ・臭いなど」一个 select。
- **カラー／素材在发布后去编辑页 `/sell/edit/<m编号>` 补设**，编辑页保存按钮是 **「変更する」**。补设后到商品页实测三项在位才算完。素材按全店统一口径。

## 配送の方法

- 配送页是 family radio：`input[name=selectedShippingMethod]`（ゆうゆうメルカリ便＝17），按 fieldset 文本匹配选中后点「更新する」；子方法（ゆうパケット等）只是价格说明，不用选。商品页只显示 family 名。
- 时序坑：从条件选择返回 create 页后立刻找「配送の方法を選択する」可能 not-found（渲染未稳），隔几秒或换窄选择器重找即通。所以驱动分两段：主流程＋finish 补配送／复核／发布。

## 终检与发布

- 获授权的品类可直接点「出品する」发布（授权范围见 mercari-ops）；其他品类或拿不准时存草稿等人工。
- 终检判据以 finish 段的配送上下文为准（主流程的同名切片有已知误报）。
- 发布后登记 listed.json（m 编号、账号、价格、货源 ID），改前备份；日志写 `hidden_files/run-<日期>-*.md`。
